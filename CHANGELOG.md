# Changelog

All notable changes to `isa-dnsproxy` are listed here.

## [1.0.0] - 2026-10-25

First complete version of the filtering DNS-to-DoH proxy.

### Added
- DNS server on UDP and TCP (same port, IPv4 and IPv6), single `poll()` loop, no threads.
- Forwarding of queries to a DoH resolver over HTTP/1.1 POST (RFC 8484, `application/dns-message`)
  using libcurl's multi interface; upstream query ID set to 0, client ID restored in the answer.
- Certificate and host name verification against `SSL_CERT_FILE`; `--insecure` to turn it off.
- Blocklist (`-b`, repeatable): hosts-format and plain-domain lines, subdomain matching,
  case-insensitive; blocked names are answered with NXDOMAIN.
- Zone files (`-z`, repeatable): A, NS, CNAME, SOA, MX, AAAA records, `$ORIGIN`, `$TTL`,
  authoritative answers (AA=1), NODATA/NXDOMAIN with SOA, CNAME chains (limited to 8 hops),
  ANY queries; names in a loaded zone are never blocked or forwarded.
- Upstream timeout (`-w`), cap on outstanding upstream requests (reported on stderr at start),
  SERVFAIL for every upstream failure (resolve, connect, TLS, non-2xx, malformed body).
- One log line per message on stdout: `<timestamp> <client> <qname> <qtype> <verdict> <rcode>`
  (verdicts: local, blocked, forwarded, invalid, dropped); IANA QTYPE names with `TYPE<n>` fallback.
- Clean shutdown on SIGINT/SIGTERM: in-flight queries are answered with SERVFAIL, exit status 0.
- Automated tests in `tests/run_tests.sh` (sections: cli, blocklist, zone, messages, local, blocked, forward),
  run with `make test [section]`.
